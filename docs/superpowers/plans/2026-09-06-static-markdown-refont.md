# Static Markdown Refont Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the marimo/Pyodide notebook pipeline with static HTML pages built from Markdown, keeping the belief math as a small hand-written JS twin and pre-rendering non-interactive plots to SVG.

**Architecture:** `build.py` renders `content/*.md` to `site/*.html` using the `markdown` package, calls `rendering/plots.py` to emit static SVG figures, and wraps everything in a page shell that loads `aif.js` (a JS reimplementation of `aif/`), `widgets.js` (Canvas 2D interactive widgets), and vendored KaTeX. The Python packages `aif/`, `worlds/`, `rendering/` stay as the tested reference implementation; a JSON fixture written by the Python cross-checks the JS.

**Tech Stack:** Python 3.10+, `markdown` (build-time only), `uv` for running, Node.js for the JS twin self-check, plain Canvas 2D + KaTeX in the browser. No framework, no bundler, no runtime CDN.

**Spec:** `docs/superpowers/specs/2026-09-06-static-markdown-refont-design.md`

## Global Constraints

- No `NB` / `NB0` abbreviations in any file name, page name, URL, or heading. Names are topic-style, explicit, standalone (e.g. `perception-and-belief`, not `NB1_perception`).
- Writing conventions: no em dash (`—`), no en dash in prose, no mid-sentence line breaks. Explanations shorter than the code they describe.
- Nothing ships Python to the browser. `markdown` is a build-time dependency only, added under an optional `build` extra in `pyproject.toml`.
- Static hosting only: no server, no recurring cost. Output is a `site/` directory of static files.
- `requires-python = ">=3.10"` stays. `markdown` must stay pure Python with no compiled transitive deps.
- Existing module self-check pattern is kept: each Python module has a `demo()` run as `python3 path/to/module.py` that asserts and prints `<name> ok`. The JS twin follows the same pattern: `node site-src/aif.js` prints `aif.js ok`.
- Do not commit. Staging and commits belong to the user. Where a step below says "Commit", stage nothing and instead stop and report that the task is ready for the user to review and commit.
- The fixed route for the first lesson is `["right", "right", "down", "down", "right", "down"]`, matching the current notebook. Seeded sensor noise uses a fixed seed so quoted counts are stable.

**Interfaces:**
- Consumes: nothing (first task).
- Produces:
  - `uniformBelief(n) -> number[]` length `n`, each `1/n`
  - `update(prior, A, obs) -> { posterior: number[], likelihood: number[], unnormalised: number[] }`. `A` is `number[][]` shape `(nObs) x (nStates)`; `A[obs]` is a row. Throws `Error` if the unnormalised sum is 0.
  - `predict(belief, B, action) -> number[]`. `B` is `number[][][]` shape `nStates x nStates x nActions`; `B[nextState][state][action]`.
  - `surprise(prior, A, obs) -> number`. Returns `Infinity` if `p(obs)` is 0.
  - `observationModel({ rows, cols, sensorNoise }) -> number[][]` shape `(rows*cols + 1) x (rows*cols)`. Lit grid, no dark tiles: the extra last row is all zeros for this lesson but kept so shapes match the Python.
  - `transitionModel({ rows, cols }) -> number[][][]` shape `n x n x 5`. No slip. Actions ordered `["up", "down", "left", "right", "stay"]`.
  - `mulberry32(seed) -> () => number` a seeded PRNG in `[0, 1)`.
  - When loaded as an ES module the above are named exports. When run directly with `node site-src/aif.js` it runs `demo()`.

```js
export function uniformBelief(n) {
  return new Array(n).fill(1 / n);
}

export function update(prior, A, obs) {
  const likelihood = A[obs];
  const unnormalised = likelihood.map((l, s) => l * prior[s]);
  const evidence = unnormalised.reduce((a, b) => a + b, 0);
  if (evidence === 0) {
    throw new Error(
      `observation ${obs} is impossible under this belief: ` +
        "every state that could produce it has probability zero",
    );
  }
  const posterior = unnormalised.map((x) => x / evidence);
  return { posterior, likelihood, unnormalised };
}

export function predict(belief, B, action) {
  const n = belief.length;
  const predicted = new Array(n).fill(0);
  for (let nextState = 0; nextState < n; nextState++) {
    for (let state = 0; state < n; state++) {
      predicted[nextState] += B[nextState][state][action] * belief[state];
    }
  }
  return predicted;
}

export function surprise(prior, A, obs) {
  const p = A[obs].reduce((acc, a, s) => acc + a * prior[s], 0);
  if (p === 0) return Infinity;
  return -Math.log(p);
}

// Action order matches worlds/gridworld.py ACTIONS.
const MOVES = [
  [-1, 0], // up
  [1, 0], // down
  [0, -1], // left
  [0, 1], // right
  [0, 0], // stay
];

function moveFrom(row, col, action, rows, cols) {
  const [dr, dc] = MOVES[action];
  const r = row + dr;
  const c = col + dc;
  if (r < 0 || r >= rows || c < 0 || c >= cols) return [row, col];
  return [r, c];
}

export function observationModel({ rows, cols, sensorNoise }) {
  const n = rows * cols;
  const A = Array.from({ length: n + 1 }, () => new Array(n).fill(0));
  for (let s = 0; s < n; s++) {
    const row = Math.floor(s / cols);
    const col = s % cols;
    const neighbours = [];
    for (let a = 0; a < 5; a++) {
      const [r, c] = moveFrom(row, col, a, rows, cols);
      if (r !== row || c !== col) neighbours.push(r * cols + c);
    }
    if (sensorNoise > 0 && neighbours.length > 0) {
      A[s][s] = 1 - sensorNoise;
      for (const nb of neighbours) A[nb][s] += sensorNoise / neighbours.length;
    } else {
      A[s][s] = 1;
    }
  }
  return A;
}

export function transitionModel({ rows, cols }) {
  const n = rows * cols;
  const nActions = 5;
  const B = Array.from({ length: n }, () =>
    Array.from({ length: n }, () => new Array(nActions).fill(0)),
  );
  for (let s = 0; s < n; s++) {
    const row = Math.floor(s / cols);
    const col = s % cols;
    for (let a = 0; a < nActions; a++) {
      const [r, c] = moveFrom(row, col, a, rows, cols);
      B[r * cols + c][s][a] = 1;
    }
  }
  return B;
}

export function mulberry32(seed) {
  let t = seed >>> 0;
  return function () {
    t += 0x6d2b79f5;
    let x = Math.imul(t ^ (t >>> 15), 1 | t);
    x ^= x + Math.imul(x ^ (x >>> 7), 61 | x);
    return ((x ^ (x >>> 14)) >>> 0) / 4294967296;
  };
}
```

```python
#!/usr/bin/env python3
"""Build the static site into site/.

Each lesson is one Markdown file under content/. This renders it to a
standalone HTML page: prose and math from Markdown, non-interactive figures
pre-rendered to SVG by rendering/plots.py, and <widget> tags left as mount
points for site-src/widgets.js. Nothing runs Python in the browser.
"""

import re
import shutil
import sys
from pathlib import Path

import markdown

ROOT = Path(__file__).parent
CONTENT = ROOT / "content"
SITE_SRC = ROOT / "site-src"

# (slug, markdown path). The slug is the output file name and the URL.
PAGES = [
    ("perception-and-belief", CONTENT / "perception-and-belief.md"),
]

# <figure src="NAME"> maps to a function returning a matplotlib Figure.
# Filled in when a page needs a static figure.
FIGURES = {}


def render_markdown(text):
    """Markdown to an HTML fragment, leaving $...$ and HTML tags alone."""
    md = markdown.Markdown(extensions=["tables", "fenced_code", "attr_list"])
    return md.convert(text)


def first_heading(text):
    match = re.search(r"^#\s+(.+)$", text, re.MULTILINE)
    return match.group(1).strip() if match else "Active inference"


def render_figures(html, out_dir):
    """Replace <figure src="NAME"> with an <img> to a generated SVG."""
    def replace(match):
        name = match.group(1)
        if name not in FIGURES:
            raise SystemExit(f"unknown figure: {name!r} (not in FIGURES)")
        import matplotlib
        matplotlib.use("Agg")
        fig = FIGURES[name]()
        svg_path = out_dir / f"{name}.svg"
        fig.savefig(svg_path, format="svg", bbox_inches="tight")
        return f'<img src="{name}.svg" alt="{name.replace("-", " ")}">'

    return re.sub(r'<figure\s+src="([^"]+)"\s*>\s*</figure>', replace, html)


def render_widgets(html):
    """Turn <widget id="NAME"> into a div widgets.js can find."""
    return re.sub(
        r'<widget\s+id="([^"]+)"\s*>\s*</widget>',
        r'<div class="widget" data-widget="\1"></div>',
        html,
    )


PAGE_SHELL = """<!doctype html>
<html lang="en">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>{title}</title>
<link rel="stylesheet" href="page.css">
<link rel="stylesheet" href="katex/katex.min.css">
</head>
<body>
<main>
{body}
</main>
<script defer src="katex/katex.min.js"></script>
<script defer src="katex/contrib/auto-render.min.js"
  onload="renderMathInElement(document.body, {{
    delimiters: [
      {{left: '$$', right: '$$', display: true}},
      {{left: '$', right: '$', display: false}}
    ]
  }})"></script>
<script type="module" src="aif.js"></script>
<script type="module" src="widgets.js"></script>
</body>
</html>
"""


def build_page(slug, md_path, out_dir):
    text = md_path.read_text()
    html = render_markdown(text)
    html = render_figures(html, out_dir)
    html = render_widgets(html)
    page = PAGE_SHELL.format(title=first_heading(text), body=html)
    (out_dir / f"{slug}.html").write_text(page)


def copy_assets(out_dir):
    for name in ("page.css", "aif.js", "widgets.js"):
        shutil.copy(SITE_SRC / name, out_dir / name)
    katex_src = SITE_SRC / "katex"
    if katex_src.exists():
        shutil.copytree(katex_src, out_dir / "katex")
    shutil.copy(ROOT / "index.html", out_dir / "index.html")
    (out_dir / ".nojekyll").touch()


def main(out_dir="site"):
    out = Path(out_dir)
    if out.exists():
        shutil.rmtree(out)
    out.mkdir(parents=True)
    for slug, md_path in PAGES:
        print(f"--- building {md_path.name} -> {out}/{slug}.html")
```

```js
import {
  uniformBelief,
  update,
  predict,
  surprise,
  observationModel,
  transitionModel,
  mulberry32,
} from "./aif.js";

const ROUTE = [3, 3, 1, 1, 3, 1]; // right, right, down, down, right, down
const SEED = 4;
const ROWS = 5;
const COLS = 5;
const N = ROWS * COLS;
const GOAL = [4, 4];

const registry = new Map();
export function mount(id, fn) {
  registry.set(id, fn);
}

const noiseChannel = new EventTarget();
let currentNoise = 0.3;

function stepsToGoal(tile) {
  const row = Math.floor(tile / COLS);
  const col = tile % COLS;
  return Math.abs(row - GOAL[0]) + Math.abs(col - GOAL[1]);
}

// Deterministic walk: true tiles, and what a seeded noisy sensor reported.
function walk(noise) {
  const rand = mulberry32(SEED);
  const trueTiles = [0];
  let row = 0;
  let col = 0;
  const MOVES = [
    [-1, 0],
    [1, 0],
    [0, -1],
    [0, 1],
    [0, 0],
  ];
  for (const action of ROUTE) {
    const [dr, dc] = MOVES[action];
    const r = row + dr;
    const c = col + dc;
    if (r >= 0 && r < ROWS && c >= 0 && c < COLS) {
      row = r;
      col = c;
    }
    trueTiles.push(row * COLS + col);
  }
  const reported = trueTiles.map((tile) => {
    if (noise <= 0 || rand() >= noise) return tile;
    const tr = Math.floor(tile / COLS);
    const tc = tile % COLS;
    const nb = [];
    for (const [dr, dc] of MOVES) {
      const r = tr + dr;
      const c = tc + dc;
      if ((dr !== 0 || dc !== 0) && r >= 0 && r < ROWS && c >= 0 && c < COLS) {
        nb.push(r * COLS + c);
      }
    }
    return nb.length ? nb[Math.floor(rand() * nb.length)] : tile;
  });
  return { trueTiles, reported };
}

function ctxOf(el, width, height) {
  let canvas = el.querySelector("canvas");
  if (!canvas) {
    canvas = document.createElement("canvas");
    canvas.width = width;
    canvas.height = height;
    canvas.style.maxWidth = "100%";
    el.appendChild(canvas);
  }
  const ctx = canvas.getContext("2d");
  if (!ctx) {
    console.error("no 2d context for widget");
    return null;
  }
  return ctx;
}

function makeSlider(el, label, value) {
  const wrap = document.createElement("label");
  wrap.style.display = "block";
  wrap.style.margin = "0 0 0.75rem";
  wrap.textContent = `${label}: `;
  const input = document.createElement("input");
  input.type = "range";
  input.min = "0";
  input.max = "0.6";
  input.step = "0.05";
  input.value = String(value);
  const out = document.createElement("span");
  out.textContent = value.toFixed(2);
  wrap.appendChild(input);
  wrap.appendChild(out);
  el.appendChild(wrap);
  input.addEventListener("input", () => {
    out.textContent = Number(input.value).toFixed(2);
  });
  return input;
}

// --- sensor-noise-walk -------------------------------------------------------
mount("sensor-noise-walk", (el) => {
  const slider = makeSlider(el, "sensor noise", currentNoise);
  const ctx = ctxOf(el, 480, 220);
  if (!ctx) return;

  function draw(noise) {
    currentNoise = noise;
    const { trueTiles, reported } = walk(noise);
    const wrong = trueTiles.reduce((n, t, i) => n + (t !== reported[i] ? 1 : 0), 0);
    const truthDist = trueTiles.map(stepsToGoal);
    const sensorDist = reported.map(stepsToGoal);

    const W = ctx.canvas.width;
    const H = ctx.canvas.height;
    ctx.clearRect(0, 0, W, H);
    const padL = 34;
    const padB = 24;
    const maxD = 8;
    const x = (i) => padL + (i * (W - padL - 10)) / (truthDist.length - 1);
    const y = (d) => 10 + ((maxD - d) * (H - padB - 10)) / maxD;

    ctx.strokeStyle = "#888";
    ctx.beginPath();
    ctx.moveTo(padL, y(0));
    ctx.lineTo(W - 10, y(0));
    ctx.stroke();

    const line = (data, color, dash) => {
      ctx.strokeStyle = color;
      ctx.setLineDash(dash);
      ctx.lineWidth = 2;
      ctx.beginPath();
      data.forEach((d, i) => (i ? ctx.lineTo(x(i), y(d)) : ctx.moveTo(x(i), y(d))));
      ctx.stroke();
      ctx.setLineDash([]);
      data.forEach((d, i) => {
        ctx.fillStyle = color;
        ctx.beginPath();
        ctx.arc(x(i), y(d), 3, 0, 2 * Math.PI);
        ctx.fill();
      });
    };
    line(truthDist, "#1f6f5c", []);
    line(sensorDist, "#c25a3f", [4, 3]);

    ctx.fillStyle = "#333";
    ctx.font = "12px system-ui, sans-serif";
    ctx.fillText("steps from the goal", padL, 8);
    ctx.fillText(
      `solid: where it actually was    dashed: where the sensor implied`,
      padL,
      H - 8,
    );
    ctx.fillText(`the two part company on ${wrong} of ${truthDist.length} readings`, padL, 22);

    noiseChannel.dispatchEvent(new CustomEvent("change", { detail: { noise } }));
  }

  slider.addEventListener("input", () => draw(Number(slider.value)));
  draw(currentNoise);
});

// --- a-matrix --------------------------------------------------------------
mount("a-matrix", (el) => {
  const ctx = ctxOf(el, 360, 380);
  if (!ctx) return;
  const readout = document.createElement("p");
  readout.style.font = "13px system-ui, sans-serif";
  el.appendChild(readout);

  let ownSlider = null;
  if (!registry.has("sensor-noise-walk") || !document.querySelector('[data-widget="sensor-noise-walk"]')) {
    ownSlider = makeSlider(el, "sensor noise", currentNoise);
    ownSlider.addEventListener("input", () => draw(Number(ownSlider.value)));
  }

  function draw(noise) {
    const A = observationModel({ rows: ROWS, cols: COLS, sensorNoise: noise });
    const W = ctx.canvas.width;
    const H = ctx.canvas.height;
    ctx.clearRect(0, 0, W, H);

    ctx.fillStyle = "#333";
    ctx.font = "11px system-ui, sans-serif";
    ctx.fillText("observation (row) vs tile (col)", 20, H - 24);

    const col7 = A.map((row, o) => [o, row[7]]).filter(([, p]) => p > 0);
    readout.textContent =
      `Standing on tile 7, the agent might see: ` +
      col7.map(([o, p]) => `tile ${o} (${p.toFixed(2)})`).join(", ");
  }

  noiseChannel.addEventListener("change", (e) => draw(e.detail.noise));
  draw(currentNoise);
});

// --- watch-it-move --------------------------------------------------------
mount("watch-it-move", (el) => {
  const controls = document.createElement("div");
  controls.style.margin = "0 0 0.75rem";
  const prev = document.createElement("button");
  prev.textContent = "previous step";
  const next = document.createElement("button");
  next.textContent = "next step";
  const restart = document.createElement("button");
  restart.textContent = "back to the start";
  controls.append(prev, next, restart);
  el.appendChild(controls);

  const ctx = ctxOf(el, 560, 260);
  if (!ctx) return;

  const noise = currentNoise;
  const A = observationModel({ rows: ROWS, cols: COLS, sensorNoise: noise });
  const B = transitionModel({ rows: ROWS, cols: COLS });
  const { trueTiles, reported } = walk(noise);

  const beliefs = [];
  let belief = uniformBelief(N);
  belief = update(belief, A, reported[0]).posterior;
  beliefs.push(belief);
  for (let i = 0; i < ROUTE.length; i++) {
    belief = predict(belief, B, ROUTE[i]);
    belief = update(belief, A, reported[i + 1]).posterior;
    beliefs.push(belief);
  }

  let step = 0;
  function draw() {
    const b = beliefs[step];
    const W = ctx.canvas.width;
    const H = ctx.canvas.height;
    ctx.clearRect(0, 0, W, H);

    // grid on the left
    const cell = 40;
    const maxB = Math.max(...b, 1e-9);
    for (let s = 0; s < N; s++) {
      const r = Math.floor(s / COLS);
      const c = s % COLS;
      const v = b[s] / maxB;
      const g = Math.round(255 * (1 - v));
      ctx.fillStyle = `rgb(${g},${g},${Math.round(120 + 135 * v)})`;
      ctx.fillRect(10 + c * cell, 10 + r * cell, cell - 1, cell - 1);
    }
    // true position ring
    const tr = Math.floor(trueTiles[step] / COLS);
    const tc = trueTiles[step] % COLS;
    ctx.strokeStyle = "#e8563f";
    ctx.lineWidth = 3;
    ctx.beginPath();
    ctx.arc(10 + tc * cell + cell / 2, 10 + tr * cell + cell / 2, cell / 3, 0, 2 * Math.PI);
    ctx.stroke();

    // bars on the right
    const bx = 10 + COLS * cell + 20;
    const bw = (W - bx - 10) / N;
    for (let s = 0; s < N; s++) {
      ctx.fillStyle = s === reported[step] ? "#e8563f" : "#4c72b0";
      const h = b[s] * (H - 40);
      ctx.fillRect(bx + s * bw, H - 20 - h, bw - 1, h);
    }
    ctx.fillStyle = "#333";
    ctx.font = "12px system-ui, sans-serif";
    ctx.fillText(`step ${step}: the sensor said tile ${reported[step]}`, 10, H - 4);
  }

  prev.addEventListener("click", () => {
    step = Math.max(0, step - 1);
    draw();
  });
  next.addEventListener("click", () => {
    step = Math.min(beliefs.length - 1, step + 1);
    draw();
  });
  restart.addEventListener("click", () => {
    step = 0;
    draw();
  });
  draw();
});

// --- dispatch -------------------------------------------------------------
function mountAll() {
  for (const el of document.querySelectorAll("[data-widget]")) {
    const id = el.dataset.widget;
    const fn = registry.get(id);
    if (!fn) {
      console.error(`no widget registered for "${id}"`);
      continue;
    }
    try {
      fn(el);
    } catch (err) {
      console.error(`widget "${id}" failed:`, err);
    }
  }
}

if (document.readyState === "loading") {
  document.addEventListener("DOMContentLoaded", mountAll);
} else {
  mountAll();
}
```
