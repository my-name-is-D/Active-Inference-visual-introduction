Active inference, by running it

An interactive tutorial. Every equation appears only after you have run the code it describes.

The organising question is a practical one: what does this give you that a reward function does not? The answer is demonstrated numerically rather than asserted, and where the framework is expensive or awkward, that is demonstrated too.

These pages run Python in your browser. The first one takes roughly 20 to 30 seconds to load, because it downloads a Python runtime along with numpy and matplotlib. Nothing is sent to a server. A laptop is strongly recommended: the notebooks put figures side by side and are cramped on a phone.

What this is not

It is not a library, and not a benchmark. For real work, pymdp is the reference implementation and the better choice. Everything here is re-derived in plain numpy because the purpose is comprehension, not deployment. Active inference also does not beat reinforcement learning asymptotically; the last notebook is about when not to use it.
